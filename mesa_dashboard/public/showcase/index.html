MESA Core

Package 0.8.0; source release publication is owner-approved. Production NO-GO remains until the required gates pass. This page presents no live benchmark or certification result.

Source-backed memory

SQLite owns catalog, assertions, mutation state and source ownership. LanceDB and Kùzu are derived projections. V4 uses one combined storage owner and principal/tenant/workspace/dataset/session authorization.

Verification boundaries

Core contract tests, comparative benchmarks and official Profile B certification have separate owners. Historical results do not measure v0.8.0. Current model accuracy and production-size capacity are not measured here.

Security and local providers

Keys bind server-authenticated principals. Scoped retrieval and untrusted-evidence rendering reduce risks but do not guarantee citation truth or legal correctness. Local provider selection requires provisioned models, credentials and network policy.

Interfaces

Versioned HTTP, sync/async Python SDKs and MCP expose scoped memory operations. Search combines vector, BM25, assertion and operational graph lanes using weighted rank fusion. Adaptive context planning is opt-in and bounded. V3 remains a separate compatibility surface.
